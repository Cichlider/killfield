## 2026-08-24 — Main 版本收尾

### 仓库与定位

- 项目收敛为 Killfield：一个 Tank Trouble 风格迷宫坦克游戏和实时 MPC 智能体。
- `engine/` 是唯一权威游戏实现；本地程序和网页均使用同一 Rust crate。
- `viewer/` 是 GitHub Page 和本地观看/对战入口；保留 MIT License。
- `main` 暂停 PPO 路线。后续 PPO 从独立 branch 开始，避免训练试验污染可运行的 MPC 版本。

### Rust 引擎与 MPC

- 游戏固定以 `25Hz / 40ms` 推进，包含迷宫、坦克运动、贴墙滑动、碰撞、反弹子弹和终局结算。
- 击杀后世界继续运行三秒，在途子弹仍可能把胜利改成双杀。
- Killfield 使用反向弹道密度场寻找射位，再在隔离沙盒中推演 18 个移动/转向/开火组合。
- 常规前视为 36 帧；通常最多承诺动作 4 帧，转向和关键事件会提前触发重规划。
- 普通轨迹按射位、guidance、瞄准、位移、弹药、风险和撞墙情况评分；出现终局时终局优先。
- 使用同一固定 Laika 和同一种子段 `20260814–20262813`，每档运行 2000 局：

  | Rays | 胜 | 负 | 双杀 | 超时 | 胜率 | 场重建均值 |
  |---:|---:|---:|---:|---:|---:|---:|
  | **512** | **1771** | 125 | 104 | 0 | **88.5%** | 0.607 ms |
  | 1024 | 1767 | 123 | 109 | 1 | 88.3% | 1.017 ms |
  | 2048 | 1767 | 132 | 100 | 1 | 88.3% | 1.686 ms |

- 512 rays 按种子顺序的最大零封为 `63` 连胜；双杀/平局保持当前连胜但不增加，失败清零。
- 另用不重叠种子段 `20262814–20264813` 复测 2000 局：`1774` 胜、`122` 负、`103`
  双杀、`1` 超时，胜率 `88.7%`，最大零封 `68` 连胜。README 采用这批新结果。
- 三组并行运行，墙钟时间和最大规划延迟受 CPU 争用影响，不作为单任务性能基准。固定种子下
  1024/2048 没有提高胜率，而场重建更贵，因此 Page 继续以 512 rays 作为最高默认精度。

### Web Viewer

- Rust 引擎编译为 `viewer/kf_engine.wasm`；网页不保留第二套 JS 物理。
- Page 提供三种模式：Killfield vs Laika、Human vs Killfield、Killfield 自对弈。
- 页面提供 512/256 rays、随机种子、对手模型、MPC telemetry 和可实时调整的参数面板。
- 记分板记录当前比分、连胜和本机历史最佳连胜。
- README 重写为当前项目说明，并使用 GitHub 可渲染的数学公式介绍 score 与终局优先规则。

### 人类控制

- 键盘移动、转向和开火直接读取当前按键集合，不累计按下时长，也不重放已经松开的输入。
- 手机支持横屏、全屏、隐藏触控层、左侧移动轮盘和右侧开火键。
- 轮盘使用 360 个世界方向，每档 `1°`；转向与前进/后退可以同时发生。
- 默认采用 `270°` 前向区和正后方 `90°` 后退区；用户可在 `0–360°` 间调整，`360°`
  表示取消后退、全部以前进对齐。
- 轮盘半径前 `10%` 平滑提高转速，超过后保持最大转速；移动从 `25%` 半径开始，在 `33%`
  达到最大速度。
- Human vs Killfield 提供“瞬间转向”开关，以及 `0–3s` 的 Killfield 开局停顿设置；默认
  `0.5s`，只暂停 AI，人类和世界立即运行。

### 操作延迟与画面

- 世界、AI和子弹保持 25Hz 权威物理；Canvas 按显示器刷新率绘制，DPR 上限为 2。
- 人类坦克不再显示落后一帧的插值。每个显示帧由 WASM 轻量沙盒调用真实墙体/贴墙求解器，
  从当前权威姿态向下一姿态预测，因此不会先画进墙再回弹。
- 人类模式每个显示帧最多补算一个物理帧；卡顿后丢弃过期时间债，不连续重放多次 MPC。
- 手机摇杆同时监听 `pointermove` 和更及时的 `pointerrawupdate`。
- 人类开火在按下沿立即进入权威引擎并播放声音；子弹立即出现、下一物理帧开始移动。
  按住开火、键盘多个开火键或触屏与键盘同时使用都不会重复触发。

### 手机展示

- 全屏横屏布局把记分板放在左侧栏、功能按钮放在右上区域，避免遮挡主要游戏画面。
- 摇杆和开火键使用适合横屏触控的固定可用尺寸；删除了无效的按钮尺寸调节选项。
- 支持标准 Fullscreen API、iOS 回退布局、横屏锁定尝试和无法锁定时的旋转提示。
- 移动端默认使用 256 rays 减少主线程压力，用户仍可切换到 512 rays。
