## 0. 这个游戏的性质（决定了哪些方法必然失效）

| 结论 | 证据 |
|---|---|
| **局面几乎不决定胜负** | 六个受控消融，学出来的 V(s) 的 R² 全在 0 附近（+0.017 / +0.033） |
| **搜索深度不买强度** | H72 vs H36 头对头 **41.1% ± 12.9**，统计上无差异 |
| **一局由一次短促的反射性交锋决定** | 上面两条的合并解释 |

**推论：AlphaZero 那一套杠杆在这个游戏上全部失效。**
不要做：学出来的价值网络当搜索叶子（P23 已试，93.5% → 87.5%）、更深的搜索、
自博弈联赛 + Elo 飞轮。

## 1. 观测（s）

### ✅ 已验证有效
- **「信息 > 激励」是全项目第一教训。**
  补观测两针（P2 弹道预演 **+8 点**、P17 导航方向 **+3 点**）
  的收益，超过整个奖励塑形调参阶段的总和（P8 之后八连 NO-GO）。
- **「不会做 X」的根因通常是「看不见 X 依赖的事实」，不是「奖励不对」。**
- **手工特征 > 学习表征（小算力下）。** P18 CNN 地图头 22.5%，惨败于直接喂路径特征。
- 每次扩观测都要验：**新 actor 与旧 actor 逐元素误差 = 0.0**（热启动可验证性）。

### ❌ 已证伪
- CNN 地图头（P18，22.5%）。
- 观测里放隐藏状态：P26 的「永久首次格奖励」依赖模型看不到的 `explored_cells`。
- 观测越界：`observation_space` 声明 low=-4/high=4，`_obs` 实际 clip 到 ±8
  （`tt_gym_env.py:250` vs `:587,612`）。SB3 不检查，加归一化层会出错。

### 纪律
- **不能进观测**：地图种子 / RNG 状态、MPC 对候选动作的评分、
  对手 AI 的内部目标栈、任何未来帧信息。
- **可以进观测**：任何「可观测元素的确定性函数」（击杀场、引导包络、
  incoming risk、路径距离）。给它不是作弊，是预计算。
- 判别标准一句话：**给"关于世界的事实"，不给"关于决策的答案"。**

## 2. 奖励（r）

### ❌ 已证伪
- **纯胜负 ±1**：12.4%，学成「苟活不开火」的退化策略。
- **稀疏塑形项会被直接无视**：v3 稀疏闪避奖励 +0.15，「被 PPO 忽略」。
- **单点行为矫正悖论（五次独立验证）**：
  P13 收紧空枪惩罚 27.7% ❌ / P14 缴械闪避特训 25.8% ❌ /
  P27 macro 接管动作 72.5% ❌ / P27c 纯规则门（两版都低于 P27b）❌ /
  P26v10 拿行为观察器标签直接训练（问题反而变多）❌。
  **原话：「已收敛策略的单点矫正会破坏自平衡」。**
  P13 的教训：**「火力体量是承重墙」**。
- **扣分买不来行为**：P32「仅在 reward 中扣碰撞分，进攻收益仍会购买顶墙」
  （33%/48% → 改成硬淘汰才降到 4.9%）。
- **逐帧存活奖励给静止发正反馈**（P28）。
- **规则数值互相打架**：P24v3 受击免疫 50 帧 > MPC 视野 48 帧，
  导致「命中后下一次合法命中完全落在视野外」，命中节奏从 1.6s/中 塌到 8.1s/中。
- **奖励塑形加猛会学出骗术**：v2 学出「同归于尽」。
  **修复方式不是继续调参，是把终局判定改回去对齐真实计分规则。**
- **目标函数塌平**：P41 击杀后 incoming_risk 恒为 0 → 10 个候选 9 个精确等于
  1500.00 → argmax 在平面上乱选 → 坦克 75 帧一动不动。
- **想象中的击杀**：14.7% 的决策是在给没发生的胜利打分，其中 51% 完全打平。

### ✅ 已验证有效
- **势函数塑形**（Ng/Harada/Russell 1999）：`F = γΦ(s') − Φ(s)`，
  可证明不改变最优策略，只改变学习速度。
- **「风格项免费午餐」**（P24v2）：带风格项的老师**同时更好看且更能打**。
  风格老师 562 分 / 1.6s 一中 / 卡墙 4.4%，纯狩猎老师 344 分 / 卡墙 42.6%。
  **好看和能打不是交易关系。**

### 纪律
三级干预，**顺序不能乱**：
```
① 补观测 ("它是看不见,还是不想?")
   ↓ 确认看得见了还是不做
② 改结构 ("是不是动作空间/决策节奏的问题?")
   ↓ 结构没问题
③ 加奖励项
```

## 3. 已知未修的 BUG

- **开火奖励打错帧**：`tt_gym_env.py:308-310` 在 `g.step()` **之前**用
  `tank.rotation` 算开火质量，但引擎里开火发生在**转向之后**
  （`game.py:204,239`）。`R_GOOD_SHOT/R_BAD_SHOT` 评的是转向前的炮口角，最多差 10°。
  所有 v2+ 奖励训出来的模型都带这个偏差。
  作者后来在 `progressive_risk_mpc_teacher.py:68` 意识到了，但从没回头修 gym。
- **P41 回归（已定位未修复）**：删掉手写的击杀后行为状态机后，暴露出
  risk 模型只算「对手未来的开火机会」，不算**已经在飞行中的子弹**。
  对手一死，感知风险归零，agent 在一个窗口内僵住。
- **killfield 权重维度错位**：导出的 checkpoint 是 1980 维，当前 `rl_env.js` 是 2011 维，
  `review_ppo.js` 的 `dense()` 用 manifest 的 1980 当列数读 2011 维观测，
  **静默截断不报错**。现在打开 rl-review.html 看到的行为不代表任何训练过的策略。
- **势能塑形与截断双记**：截断时既加 `R_DRAW=-0.5` 又照常算势能项，
  同时 SB3 对 truncation 做 value bootstrap → 轻微重复计数。

## 4. 算法与训练（PPO）

### ❌ 已证伪
- **恒定 lr 长训会崩且不可逆**：P16 续训到 60M 步，
  **约 2M 步后性能崩塌，永远回不来**。
  → PPO 精修的有效窗口约 **2M 步**，必须上 LR schedule。
- **BC 之后直接 PPO 会崩**：killfield 的 BC 起手 run，
  validation accuracy 88.0% 但初始 return **−3.14**（比无 BC 的 −1.56 还差），
  初始熵只有 **0.57**（几乎确定性，零探索）。

### ✅ 已验证有效
- **BC 的正确用法**：裸克隆无用（8.1%），但作 RL 热启动极佳
  ——**3 倍学习速度 + 能找到新的行为盆地**。
- **价值头预热冻结**：`train_ppo.py:210-224` 已实现，value 没学好就更新 policy 是崩溃常见原因。
- **小头挂在冻结冠军上**：8 月线唯一晋升成功的做法（P27b risk/value 小头 +1.1 点）。
  反例是 P27 macro 直接接管动作 → 72.5%。

### 从没做过（诚实缺口）
- **算法对比**：PPO 是第一天的默认项，从没和 DQN/SAC 做过头对头。
- **自博弈**：每一局 PPO 训练打的都是同一个固定脚本 AI（Laika）。
  没有联赛、没有 checkpoint 池、没有 Elo。
  `arena.py` 只是成对 A/B 晋升门槛，不是自博弈系统。

## 5. 蒸馏 / 模仿（这是全项目最大的坑）

**主线矛盾：老师 96–100%，学生 64–88%。差距来自「学生观测里不存在老师用来排序动作的信息」。**

### ❌ 已证伪
- **argmax 标签不可教**：MPC 候选中**中位 14/18 并列**，
  完美预测器的 top-1 上限只有 **11.9%**。硬取 argmax 学生只学到糊掉的平均。
  P19 argmax BC 蒸馏 30.8%（老师 96%）。
- **top-1 命中率是误导指标**，正确度量是 **regret**（选的动作比真正最优差多少分）。
- **观测里缺动作条件信息**：P21a 评分回归只有 14%，
  诊断是「观测全是动作无关特征，标签问的却是往哪躲能活」。
- **闭环分布偏移**：P25v1 直接拿老师自打的数据蒸馏 → 13.8%。
- **混合语义标签**：P29「older raw-score 与 P28 adjusted-value 标签混训」→ 拒收。
  P29c 平均 h48/h72 的冲突标签「产生平滑数值目标但不是决策目标」。
- **特权老师压不进网络**：exact-state teacher（能看对手真实 RNG 和内部目标栈）
  100% 胜率，但蒸馏后 action agreement 卡在 **22.5%**，
  observation-only 安全分类器 **held-out 0%**。

### ✅ 已验证有效（P21 成功管线三原则）
1. **回归全部 18 个动作的评分地形**，不学 argmax
2. **配对种子**：同一决策步的所有候选共用一个沙盒 RNG 种子做配对比较
3. **只在宏动作重规划帧采样**

- **P21b 关键跳变**：给了 408 维全知观测 + 评分回归 → 从 14% 跳到 **62.2%**。
  同一个方法，只改观测，涨 48 点。
- **expert iteration / DAgger 跑通了**：曲线 **+4 / +1 / 平台**，两轮见顶。

## 7. 评估纪律（最被低估的资产）

### 已测量到的偏差
- **100 局训练回调 vs 1000+ 局新种子，系统性偏差 ±9 点。**
  好几次差点因为小样本波动做出错误的版本回滚决定。
- **40 局过、300 局崩**：suppress-only `40@970000 = 90.0%` → `300@970000 = 84.0%` → 拒收。
- **胜率上去但行为变蠢**：P26v9 iter10 `40@970000` 95.0%，
  但 shots 3.77 / hit 13.9% / blind_fire 32 → 拒收。
- **R² 虚高全是泄漏**：按样本切分而非按整局切分，
  同一局内不变的迷宫位图特征泄漏 → 训练集 R² 0.988，换新地图就是噪声。
- **训练分布 ≠ 部署分布**：P28 随机采样撑满 18.8%，
  确定性 argmax 全程静止。

### 纪律
- 训练中的快速评测只做粗筛（80–200 局配对种子），**不可作数**。
- 正式结论必须：**1000+ 局从未在训练中出现的种子段**，且在**第二个独立种子基**上复现。
- **永远双指标**：先杀率（first-kill）和真实胜率（活到 round_end）
  ——两者能差 15–29 个百分点，只看先杀率会被「同归于尽」骗术骗过去。
- **预注册判据**：跑之前先写死"什么算通过"。
- **同维度不同语义的数据严禁混合。**

## 8. 「像人 / 观赏性」

这是一等目标，项目里叫**「观赏性」**。
用户原话：「我希望这样训练出来的 ai 是能直接打原版，并且打出一定观赏性的」。

### ❌ 已证伪
- **写 if 规则做不到**：P27c 纯规则门两版都低于 P27b，
  「简单规则门只会让策略更犹豫、把局拉长」。
- **拿行为检测器标签直接训练做不到**：P26v10 iter11（80.0%、DD 7.5%、问题反而变多）。
  根因：**「大多数 missed_fire_window 帧不是老师确认的真开火帧」——检测器有假阳性，
  当奖励就是在奖励噪声。**
- 用户对硬状态机的原话：「他这个状态机切状态太伤了，感觉是你在约束 AI 打游戏。」

### ✅ 有效方向
- **补观测 / 补世界模型，而不是加战术规则。**
  P17（加导航观测）和 P24v2（势能风格项）两次验证了「补信息能同时变好看和变强」。
- **行为观察器只做诊断，不做奖励。**
  `p26_behavior_observer.py` 的六类可量化定义值得保留：
  `missed_fire_window` / `blind_fire` / `stutter_stall` /
  `dead_end_stall` / `passive_map_control` / `post_kill_fire`。
  （冠军 iter05 在 40 局里 missed_fire_window 328、stutter_stall 246。）

## 9. 性能基线（用于判断优化是否值得）

| 项 | 数字 |
|---|---|
| Python 引擎裸跑（无头） | 6,000–12,000 帧/秒 |
| Python gym 含观测（76 维 / 125 维） | 1,247 / 763 决策步/秒 |
| Python PPO 训练（12 进程） | 2,700–4,500 步/秒；60M 步 ≈ 6–7 小时 |
| **killfield JS 桥（32 env，带 2048 射线击杀场）** | **4,100 env-steps/s = 244 μs/step** |
| killfield `game.step()` 本身（估） | 5–20 μs → **引擎只占 5–8%** |
| 击杀场重建 | **12.2 ms/次**（按敌人所在格缓存，换格才重建） |
| killfield MPC 单帧决策 | 中位 0.56 ms，p95 15.8 ms |
| 决策延迟演进 | 全量 MPC 91ms → 混合 K=12 36ms → 纯网络 8.6ms → P38 特权蒸馏 0.83ms |

**结论：瓶颈是观测编码（击杀场），不是引擎。**
优化性价比排序：降射线数 > 多线程 > 砍观测维度 >> 换语言。
