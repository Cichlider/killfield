回合结束时结算一次

$$R=R_{\text{outcome}}+S(r),\qquad r=\frac{\text{动作变更次数}}{\text{回合帧数}-1}$$
$$R_{\text{outcome}}=\begin{cases} 1, & \text{胜，}t\le 10\text{s}\\[2pt] 1-\dfrac{1}{2}\cdot\dfrac{\ln(t/10)}{\ln 3}, & \text{胜，}10\text{s}<t\le 30\text{s}\\[6pt] -0.1, & \text{双亡}\\[2pt] -1, & \text{失败，或 30 秒平局} \end{cases}$$
$$S(r)=\begin{cases} 0.25, & r\le 0.13\\[4pt] 0.25\left(1-\dfrac{\ln(r/0.13)}{\ln(1/0.13)}\right), & 0.13<r\le 1 \end{cases}$$

胜负决定任务目标，时间项反对拖延，平滑分表达行为风格。0.13 是实测值：Laika 与 512-ray 规划器在同一动作三元组下的变更率分别为 12.9% 与 12.7%。平滑分上限 0.25 受一条不等式约束——最差的胜（+0.5）必须仍然高于最好的双亡（-0.1+S），因此 S<0.6。

02

训练对手和评测对手是同一个东西吗？

代码给出的事实更复杂：训练池直接包含同一个 512-ray 规划器。

先写边界：这不是零接触评测。训练每局按 10% / 10% / 80% 抽取 Laika、同一个 512-ray Killfield、冻结学习祖先；训练与评测都走同一引擎构造路径，使用 512 rays 与同一 L1 对手模型。dodge_safety 不是一个简化训练对手，而是提供给 Hybrid 的 24 帧特征。

MPC 公式中，F 是场风险，G 是 guidance progress，C 是 chain gain，Q 是开火机会，紧随的 C / A 分别是 concentration 与 alignment gain，W 是贴墙帧，I 是 incoming risk，Δx 是位移。field-ascent 项当前系数为 0；这是代码事实，不因「不显著」而从定义中藏掉。

训练暴露与评测判据至此摊开，读者可自行判断 92.7% 有多少来自已知对手覆盖。Killfield 自身零训练、零梯度，却已能赢多数人类玩家，因此「赢人类」检验的是系统整体强度，不是学习算法；方法层面的因果主张依靠消融。

先写边界：受控实验是从同一成熟 v11 祖先出发的匹配续训，不是从头训练。各 arm 的追加步数（4,194,304）、奖励、对手池和种子 21/22/23 均相同。在这个范围内，只让网络读到 dodge，较 Base 对 Laika / Killfield 提高 +9.53 / +7.30 pp，两个三种子差值区间都不含 0；在可读 dodge 上再加动作对齐捷径只增加 +1.23 / +2.33 pp，区间均跨过 0。

05

「搜索只生成局部特征」经得起逐维清点吗？

严格口径 53 维依赖前向模拟；宽口径计入几何搜索后为 76 维。

边界先写：Hybrid 不读取 Killfield 的 512-ray 密度场，但确实消费规划器式的中间计算。严格按弹道 / lookahead 口径，10 维瞄准辅助 + 30 维逐弹预测 + 4 维威胁摘要 + 9 维 dodge，共 53 / 1028（5.16%）；再计入 16 维墙体射线与 7 维 BFS 路径 / 梯度 / 死路量，宽口径为 76 / 1028（7.39%）。密度场相关通道为 0。

证据支持的贡献是：把 action-conditioned lookahead 输出作为观测信息，在匹配续训中带来 +9.53 / +7.30 pp；再把这些输出直接接到对应动作 logits，没有可测增益。学习策略是在消费规划器式中间产物后超越完整规划器，而不是「学习超越规划」。
06

「抖动是 loss 问题」是实验结论吗？

不是；它是梯度路径论证，正文按这个证据等级表述。

边界是：没有一组只提高终局动作平滑奖励、其余完全固定的干净对照。历史记录称 [0, 0.25] 的 smooth bonus 在八次 run 中未见效果，但这些 run 被重启等因素混淆。因此这里只保留基于时延与方差的论证：终局奖励约 200 帧后才经 GAE 归因到一次抖动，entropy 则每帧提供解析梯度。

L3\(+0.05\mathcal L_{\rm wall}\)完全撞停后反对继续同向油门
L4persist 比较移动 \(m(a)=\lfloor a/2\rfloor\)，不比较开火位避免把开火切换误判为走位抖动
\(\mathcal L=\mathcal L_{\rm clip}+0.5\mathcal L_V-\beta_H\mathcal H+0.02\mathcal L_{\rm persist}+0.05\mathcal L_{\rm wall}\)

这些干预确实改变了目标症状：采样动作变更率 66%→54%，继续训练后约 15%；转向反转率 22.6%→0.6%；硬撞墙率约 0.8%。但 persistence 也制造了新退化——长期静止从 18.4% 升到 48.0%。应对方式是允许前 8 帧中性动作、之后才生效的可覆盖 actor bias，而不是 action mask。这些前后测量支持「症状被控制」，却不能替代缺失的 reward-vs-loss 干净对照。

07

你怎么知道自己的 PPO 是对的？

一个边界索引检查通过；更广的集成验证仍未完成。

关键边界是：GAE 数值对拍、termination / truncation 单测、单状态收敛和同机 LunarLander / CleanRL 对照仍尚未完成。因此本页不宣称 PPO 栈已被独立验证。

已核查的一项是边界索引：env.step(action) 后，done_buf[t] 保存 transition \(s_t,a_t\to s_{t+1}\) 是否终止，因此 alive = 1-done_buf[t] 没有差一帧。CleanRL 写成 \(dones[t+1]\) 是不同 buffer 约定下的同一事实。

生产训练每个 update 收集 256 环境 × 128 步 = 32,768 transitions，以 gamma .999、lambda .95 计算 GAE，在整个 rollout batch 上归一化 advantage，再打乱成 8 个 minibatch、优化 4 epochs（共 32 个 optimizer steps）。训练从 categorical 分布采样动作；固定评测取 argmax。

termination / truncationbuffer 不区分二者。30 秒上限被主动设计为 −1.0 的 MDP 内带惩罚终局以塑形，所以在本任务中按 terminal 处理符合定义；原样接到 Gymnasium TimeLimit 会出错。这不是偶然对齐，而是任务定义。
Value loss无 clipping。\(\mathcal L_V=0.5\,MSE\)，外层再乘 value coefficient 0.5：有效权重为 0.25×MSE，是无意的双重折半。
归一化无 reward 归一化、无 running observation stats；Rust 按固定物理范围缩放，因此也不存在评测时忘记冻结 running stats 的问题。
08

用什么指标判断训练健康？

历史遥测不足；现在补齐前向记录，不伪造历史曲线。

边界先写：在 4.78 亿步、17 个版本中，approx_kl 与 clipfrac 未记录，entropy 取的是 32 个优化 minibatch 中最后一个，而非 update 均值。因此无法用可信诊断量重新裁决历史上的「坍缩」担忧。训练器现已按 update 汇总 entropy、policy loss、value loss、approximate KL 与 clip fraction；这是向前生效的补测，不是回填出来的历史曲线。

这很重要：项目选择固定对手池 + 冻结祖先而非纯自博弈，部分动机是规避坍缩与循环遗忘，但当时监测坍缩的指标本身就有噪声。entropy 系数还按血统步数衰减：478M / 800M 时约为 0.004，只剩初值 40%。因此 entropy 下降可能来自调度，不能自动解释成自博弈坍缩。

09

消融实验有没有被调度或血统污染？

已完成的匹配 arms 起点与调度区间一致；但只有三个种子。

边界是：三个种子足以暴露明显不一致，不足以给出紧的总体估计；seed 区间重叠的结果按不确定报告。dodge、ammo、distillation 三组研究的所有完成 arms 都从 trained_steps=404,881,408 开始，恰好追加 4,194,304 步后停在 409,075,712，使用同一 600M 步 LR / entropy 调度和 seeds 21/22/23。因此匹配差异不能由不同退火区间解释。

之所以追踪血统，是因为它曾经失效：v7 来自一次误把学习率重置到初值的 run。此后迁移区分 resume（权重、Adam、调度全恢复）与 init-from（兼容权重、重建 Adam、显式继承 trained_steps）。观测扩容时新列补零；actor 新通路采用 \(\ell'=\ell+\alpha g(s),\alpha_0=0\)，并要求固定观测上 step-0 的 18 个 logits 完全一致。v14 的 idle penalty 是公开的例外：它有意在 step 0 改变行为。

10

这个策略能被针对吗？

真人对局未发现稳定克制法，但没有做 best-response 搜索。

边界紧跟事实：大量真人对局没有发现稳定克制打法，但人类探索与梯度搜索差异很大；本项目尚未对冻结 v17b 训练 exploiter。KataGo 的先例值得警惕：对抗策略对一个超人围棋系统取得超过 97% 的胜率，漏洞公开后业余棋手也能复现循环攻击。

10/10/80 的 Laika / Killfield / 冻结祖先池是一项主动权衡：固定锚点和不可变祖先降低坍缩与循环遗忘风险，代价是可达策略多样性受池子覆盖面限制。

11

v16 的真人成绩与 v17b 的基准数字是什么关系？

不同 checkpoint、不同协议，不能并列换算。

边界先写：真人长局用的是 v16；97.5% / 92.7% 固定基准来自 v17b。同会话 round 受地图、连续状态和玩家适应影响而相关，有效样本量小于名义局数。

L_Shy_P 这一组照实呈现为 80–24–12，其中 12 场是双亡。按本项目奖励，双亡为 −0.1、接近中性，因此不重新归类。在更广的真人记录中，104 场分胜负窗口为 76.9% [69%, 85%]，258 场分胜负窗口为 77.5% [72%, 83%]；区间重叠，数据只说明未检出下滑，不证明人类永远无法适应。

训练规则严于部署规则

真人对局全部使用原版规则：没有 30 秒超时。训练主动把 30 秒超时定义为 −1.0 的 MDP 内终局，因此策略把「必须在 30 秒内解决战斗」的先验带进一个并不要求它这么做的环境。这在结构上禁止消极对峙，也解释了进攻性风格；它是自我施加的约束，因为部署环境反而更宽松。尚未训练「原版规则、无超时惩罚」对照，因此这条先验的影响大小仍是 limitation。

12

AI 赢人类靠的是反应速度吗？

游戏重站位与弹道预埋；但正式评测仍是零帧延迟。

边界明确：正式评测使用零帧延迟。viewer 提供 1/2/3 帧档位，但尚无正式对照；3 帧是 120 ms，仍短于约 200 ms 的人类反应量级。并且零延迟训练的策略按 40 ms 动作预算校准，推理时改成三帧是分布偏移，不只是「同一策略慢一点」。干净证据需要把延迟做成训练域随机化维度或写入观测。

机制上，Tank Trouble 不是精确瞄准游戏：转向慢、反弹弹道持续存在、弹药有限、迷宫墙体使站位、封锁与弹道预埋成为核心。这说明反应速度不是唯一变量，但不能消除零延迟混淆。

浏览器中的一帧

  1. requestAnimationFrame 累计真实时间；每满 40 ms 触发一次物理 tick。
  2. 保存上一份可渲染状态，供稍后插值。
  3. WASM 从权威状态编码 observation、bullet mask 与 dodge_safety。
  4. Hybrid 在本地前向、取 argmax，并把动作写回引擎。
  5. 对手决策；双方动作同时消费，物理推进。
  6. 客户端读取新状态，处理声音与终局事件。
  7. 渲染在两份权威状态间插值；刷新率只改变平滑度，不改变 25 Hz 规则。
延迟含义作用
决策计算Hybrid 前向或 Killfield 搜索明显低于 40 ms 就能赶上待执行 tick。
物理采样权威状态按 40 ms 网格更新事件理论上等待 0–40 ms。
显示插值在最近两份权威状态间绘制纯视觉，不给策略额外反应时间。
